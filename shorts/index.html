Shorts Factory

Kişisel kısa video otomasyon aracı · YouTube API Servisleri ile çalışır

Shorts Factory, geliştiricinin kendi YouTube kanalı için kısa videolar hazırlayan ve YouTube API Servisleri aracılığıyla yükleyen kişisel bir araçtır. Herkese açık bir hizmet değildir; başka kişilerin hesaplarına erişmez.

Ne yapar?

Bilgi, quiz ve hikâye formatında kısa videolar üretir ve bunları YouTube Data API'nin videos.insert yöntemiyle yalnızca geliştiricinin yetkilendirdiği kendi kanalına yükler. YouTube erişimi sadece video yükleme izniyle (youtube.upload) sınırlıdır.

Yasal

Shorts Factory

Personal short-video automation tool · powered by YouTube API Services

Shorts Factory is a personal tool that prepares short videos for the developer's own YouTube channel and uploads them through the YouTube API Services. It is not a public service and does not access anyone else's accounts.

What it does

It produces short fact, quiz and story videos and uploads them with the YouTube Data API videos.insert method, only to the developer's own channel that the developer has authorized. YouTube access is limited to the upload permission (youtube.upload).

Legal

By using this tool you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.
